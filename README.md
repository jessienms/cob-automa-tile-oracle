# 버건디의 성 — 오토마 타일 신탁

🔗 **바로 실행하기: https://jessienms.github.io/cob-automa-tile-oracle/**

모바일 브라우저로 위 링크에 접속한 뒤 "홈 화면에 추가"하면 앱처럼 사용할 수 있습니다.

## 왜 만들었나

보드게임 **버건디의 성(Castles of Burgundy)**을 혼자 플레이할 때 쓰는 팬 제작 솔로 모드(오토마)를
진행하려면 매 라운드 오토마가 어떤 타일을 뽑고 어떻게 배치하는지 규칙을 계속 대조해야 해서,
그 판정 과정을 대신 처리해주는 도구로 만들었습니다.

## 원본 출처

- 게임 규칙: *버건디의 성* 20주년 기념판 공식 룰북
- 솔로 모드(오토마) 규칙: 팬 제작 솔로 모드 문서

두 원본 문서는 저작권 및 개인 참고용 목적상 이 저장소에는 포함하지 않았으며,
이 도구는 해당 규칙을 웹에서 편하게 실행하기 위해 개인적으로 만든 비공식 팬 제작물입니다.
